# SuperMimic Browser Playback

Static browser sim2sim demo for SuperMimic.

- MuJoCo WebAssembly
- ONNX Runtime Web
- Three.js

The prebuilt `dist/` directory is published to GitHub Pages through the workflow
in `.github/workflows/pages.yml`.

After the repository is created, enable:

`Settings -> Pages -> Build and deployment -> Source: GitHub Actions`
